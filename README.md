# 家庭赚¥指南（Housework Points）

一个帮助家庭培养孩子"劳动换奖励"习惯的积分管理 Web 应用。孩子通过完成家务任务赚取积分（元），兑换心愿和奖励，配合连续打卡和成就系统形成正向激励闭环。

> 纯前端应用，数据保存在浏览器 localStorage，无需服务器、开箱即用。

## ✨ 功能特性

- **👨‍👩‍👧 家庭成员管理** — 添加多位家庭成员，独立余额与记录
- **🧹 家务任务系统** — 自定义赚钱任务 / 扣款任务，按成员统计本周收支
- **💵 基础零花钱** — 设置每周必完成项，全部完成后一键领取基础零花钱（含撒花特效 + 到账弹窗 + 金额飞行动画）
- **🎁 奖励商店** — 孩子用赚到的钱兑换奖励，家长审核确认
- **🌟 心愿系统** — 设置心愿目标、累积进度，达成后记录"已达成心愿"
- **🔥 连续打卡** — 完成任务的连续天数记录，断签自动重置
- **🏅 成就系统** — 12 个成就（打卡坚持 / 财富积累 / 勤劳之星 / 里程碑），解锁弹窗通知，部分成就发放金币奖励
- **📊 记录与统计** — 每日收支记录、成员排行、本周统计
- **💾 数据备份** — 一键导出 / 导入 JSON 数据

## 🚀 使用方法

```bash
# 方式一：直接双击打开 index.html
# 方式二：本地服务器（推荐，避免浏览器限制）
python -m http.server 8888
# 然后访问 http://localhost:8888
```

首次打开会自动加载示例数据，也可在「我的」页点击"加载示例数据"或"清理缓存"。

## 📁 项目结构

```
housework-points/
├── index.html      # 页面结构
├── css/style.css   # 样式（移动端风格）
└── js/
    ├── store.js    # 数据层（localStorage 读写、成就/打卡逻辑）
    └── app.js      # 应用逻辑（渲染、交互、动画）
```

## 🧩 技术说明

- 原生 HTML / CSS / JavaScript（ES6），无任何第三方依赖
- 数据层与视图层分离：`store.js` 只负责数据，`app.js` 只负责界面
- localStorage 持久化，`exportAll/importAll` 支持全量备份迁移
